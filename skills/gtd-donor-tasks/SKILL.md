# GTD Donor Tasks — Cross-System Task Management

Manage donor-originated tasks from within the GTD system. These are tasks auto-generated by the Donor Management DB (thank-you calls, follow-ups) that appear as actionable items in GTD.

## Invocation Triggers

**Explicit:** "show donor tasks in GTD," "complete that donor task," "donor follow-ups in my task list."

**During review:** Weekly review Step 8 checks these. Morning briefing also surfaces pending donor tasks.

## How It Works

```
Donor DB (auto_tasks.py)  →  Creates tasks  →  GTD API reads them  →  Agent completes  →  Status pushed back
```

1. **Donor DB auto-generates tasks** based on rules (first gift → thank-you, returning donor → thank-you, large gift → thank-you)
2. **GTD API mirrors these tasks** so they appear alongside other next actions
3. **Agent completes via GTD API** → status is pushed back to the Donor DB automatically

## Operations

### List Donor Tasks in GTD

```
GET https://gtd-api.fly.dev/donor-tasks
Header: X-API-Key: [from TOOLS.md]
```

Filter by status:
- `?status=next_action` — active/pending tasks

### Get Donor Task Detail

```
GET https://gtd-api.fly.dev/donor-tasks/{id}
Header: X-API-Key: [from TOOLS.md]
```

Returns the task with donor context: contact name, gift amount, task type, and reason for generation.

### Complete a Donor Task

```
PATCH https://gtd-api.fly.dev/donor-tasks/{id}/status
Header: X-API-Key: [from TOOLS.md]
Body: { "status": "completed" }
```

This marks the task complete in GTD **and** pushes the completion back to the Donor Management DB. After completing, suggest logging the interaction: "Want me to log this call in the donor history?" (Use the `donor-log` skill.)

### Cancel a Donor Task

```
PATCH https://gtd-api.fly.dev/donor-tasks/{id}/status
Header: X-API-Key: [from TOOLS.md]
Body: { "status": "deleted" }
```

Maps to "cancelled" status in the Donor DB. Use when a task is no longer relevant (e.g., contact is unreachable, task was created in error).

Endpoint and credentials in `/workspace/TOOLS.md`. Full API spec at https://gtd-api.fly.dev/openapi.json.

```
GET   /donor-tasks              — list donor tasks (?status=next_action)
GET   /donor-tasks/{id}         — donor task detail
PATCH /donor-tasks/{id}/status  — update status (completed, deleted)
```
